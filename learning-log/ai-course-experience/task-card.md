# 任务卡：只增加状态筛选

## 需求

本地小事板按全部/未完成/已完成筛选。不增加账号、分类、云同步、模型接入或数据库迁移。起始应用的CRUD和文本安全呈现保留。

| 输入/行为 | 预期 |
|---|---|
| 缺省、status=all | 全部任务，保持id顺序 |
| status=open、done | 只显示对应布尔状态 |
| invalid、空值、重复status | 明确400，不静默返回全体；空/重复策略为本次自行明确的决定 |
| 无匹配 | 中文空状态，可切回其他筛选 |
| 查询 | 不写数据，结果顺序不变 |
| 当前筛选内改变完成状态 | 刷新后按当前筛选移入/移出 |
| 筛选加载失败 | 控件与保留的旧结果一致，明确恢复方式 |
| 快速切换 | 旧成功/旧失败不能覆盖新结果 |
