# 现代软件开发：从想法到可靠作品

**给普通编程爱好者的中文实践课程。预备课 + 10 周，每周 4–6 小时。**

你会和 AI 一起提出需求、阅读代码、做小步修改、验证结果，最后交付一个别人也能运行的应用。主线作品叫「小事板」：记录任务、从笔记提取行动，并逐步加入你自己的功能。

本课程依据 Stanford CS146S 的公开大纲及作业进行**独立重构**，不是斯坦福官方课程、认证项目或课堂逐字稿。2025 完整版为主线；2026 已公开的新方向单列为扩展。资料核对日：**2026-09-28**。参见 [来源与改编映射](docs/sources.md)。

## 现在开始

1. 先读 [学习指南与环境准备](docs/start.md)。不会终端、Git 或 Python？从 [第 0 课](lessons/00-foundations.md) 开始。
2. 下载本仓库 ZIP 并解压，或克隆到自己的电脑。
3. 在仓库根目录运行以下命令。Windows 将 `python3` 换成 `py -3.12`；已经激活虚拟环境时可用 `python`。

```bash
python3 tools/check.py
python3 -m app.server
```

看到地址后，打开 <http://127.0.0.1:8000>。创建一条任务、刷新页面，确认它还在；终端按 Ctrl+C 停止。Python 3.12 是验证基线，主线无第三方依赖，不需要 API Key。

## 选择适合自己的路线

| 路线 | 适合谁 | 每周安排 | 怎么使用 AI |
| --- | --- | --- | --- |
| 基础线 | 会一点代码，或刚完成预备课 | 4–6 小时；10 周 | 有可用聊天工具就手动粘贴小段代码；没有也可完成确定性练习 |
| 完整 AI 线 | 已有任意可用编码助手 | 5–7 小时；10 周 | 增加真实模型对照、Agent、MCP 集成 |
| 慢速线 | 下班后、周末学习 | 每周 2–3 小时；20 周 | 每课拆为「理解 + 实作」两周 |

完全没接触过编程，预备课预留 6–10 小时。没有真实 AI 调用时可以完成工程基础线，但不能声称已验证模型效果或实际 Agent 行为。付费服务与本地大模型均为可选，不承诺任何教育优惠或免费额度。

## 学习方式

每周先预测结果，再动手运行，最后解释差异。每次只新增一个可以验收的行为。AI 的回答、测试通过和用户满意是三种不同证据；不要互相替代。

提交材料用 [周报模板](templates/weekly-report.md)。不需要向原课程教师添加协作者，也不向 Gradescope 提交。练习放自己的仓库分支；若要贡献课程材料，见 [贡献指南](CONTRIBUTING.md)。

## 仓库导航

- `lessons/`：11 份可自学讲义，包含概念、演示、练习、自检答案。
- `app/`、`tests/`：原创本地应用和契约测试；已有 CRUD 是练习起点。
- `labs/`：离线评测、Agent 轨迹、MCP 集成入口和评审案例。
- `templates/`：需求、设计决策、评审、事故记录、周报。
- `docs/`：开课指南、来源、毕业评分、学习组织与工具替代方案。
- `tools/`：统一检查与日志统计；GitHub Actions 使用同一检查命令。

`app.server` 只面向本机单用户练习，没有账户与权限体系。不要把该服务器直接暴露到公网。毕业可以通过本地可复现包完成；上线进阶的差距见 [交付指南](docs/delivery.md)。
