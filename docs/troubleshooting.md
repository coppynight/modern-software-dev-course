# 常见卡点与求助方式

| 现象 | 先检查 | 下一步 |
| --- | --- | --- |
| python 找不到 | 当前系统及安装版本 | Mac/Linux 用 python3，Windows 试 py -3.12；安装后重开终端 |
| No module named app | 当前目录是否包含 app | 回仓库根目录，用 `python -m app.server`，不要直接执行 app/server.py |
| 8000 已被占用 | 是否已有项目窗口在运行 | 停止自己的旧进程，或 `python -m app.server --port 8001` |
| 网页访问失败 | 服务是否启动、端口是否一致 | 使用终端显示的 http 地址，不用 https |
| 403 | 是否使用代理域名、局域网 IP 或跨站请求 | 该项目仅支持 localhost/127.0.0.1；不要删除检查来公开服务 |
| 规则漏掉自然语言 | 是否带课程定义的标记 | 这是规则基线边界；选学 S01、S02研究模型替换 |
| 修改后没有变化 | 文件路径、保存状态、服务器进程 | 保存文件，停止并重启 Python；前端刷新 |
| 数据库错误 | 路径是否可写，是否把 DB 换成目录 | 停止服务并备份，使用新的 `--db data/practice.db` 诊断，勿直接删除原数据 |
| Git 提交被拒绝 | 作者配置、凭据、仓库权限 | 用自己账号的正常 GitHub 登录流程，不把 token 写进 remote URL |
| MCP 找不到工具 | 解释器与模块启动路径 | 先跑 smoke.py；确认安装在正确虚拟环境，STDIO 日志只写 stderr |
| AI 提供不存在命令 | 是否有实际文档和执行输出 | 查官方文档、版本；让助手明确未验证项 |

## 有效求助模板

「我在 [系统/版本]，仓库提交 [SHA]，从根目录执行 [命令]，期望 [行为]，实际 [报错最后几行和必要上下文]。已尝试 [动作]，结果 [事实]。」附最小相关 diff，不发数据库、密钥、完整私有会话或个人笔记。

连续 30 分钟没有新证据时停下反复安装，缩小问题：能否运行 `python --version`？能否导入 `app.domain`？业务测试是否通过？网页失败还是服务没启动？逐层排除比一次重装全部工具有效。
