# 主线完成清单

[课程首页](../README.md) · [任务卡](../templates/task-card.md)

全程交付同一个功能与一份任务卡。满足下面五项即可，不要求完成选学、每周打分、多个技术栈或额外毕业项目。

| 单元 | 可检查的成果 |
| --- | --- |
| 1 | 需求与上下文清楚；正常、边界、失败场景都有预期 |
| 2 | 功能可运行；关键修改可解释；一条真实调用与处理记录 |
| 3 | 新会话能找到入口；检查可重复；文档与接口一致 |
| 4 | 人工与 AI 实际参与评审；重要意见有核验与处理 |
| 5 | 使用与失败路径通过；干净目录可复现；限制明确 |

用文件、运行结果或观察记录作为证据。未执行的项目写未验证；离线桩、模拟轨迹与真实 AI 调用分开，不用自动检查代替页面验收。

## 选学如何验收

选了哪个专题，就按那份讲义的标准自检，不影响主线进度。若选择 [完整毕业作品 S10](../optional/10-capstone.md)，可再使用 [进阶评分表](../optional/project-assessment.md)；这是额外挑战，不是紧凑主线要求。
