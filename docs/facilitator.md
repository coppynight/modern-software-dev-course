# 共学组织建议（选学）

[返回目录](../optional/README.md)

按 5 个主线单元组织 5 次共学。每次约 90 分钟，剩余实作自行完成；可按团队节奏拆分，不要求全员先上基础课。

开课前只确认项目能运行。卡在语法、环境或 Git 的学员，分别补 [S00](../optional/00-foundations.md) 或 [安装与 Git](../optional/setup-git.md)，已经具备基础的直接进入主线。

每次：15 分钟讲关键概念，20 分钟演示，40 分钟继续同一功能，15 分钟交换证据。只更新一份任务卡。

| 单元 | 主持时重点追问 |
| --- | --- |
| 1 | 什么行为才算做对？ |
| 2 | 是模型说了，还是工具真正执行了？ |
| 3 | 新会话为何还需要重复解释？ |
| 4 | 评审意见能否被证据支持？ |
| 5 | 别人能否按说明运行与恢复？ |

基础答疑与深入挑战单独安排，不把选学重新变成必修。结束时交换项目与 README，按 [主线完成清单](assessment.md) 交叉复现。允许记录不知道、未验证或工具受限，避免为完成要求编造结果。
